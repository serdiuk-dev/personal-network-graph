# PNET на iPhone: продление подписи и доверие

Актуально на 18 октября 2026. Учётная запись: бесплатная Personal Team.

## Как часто

Это не лицензия PNET, а профиль подписи Apple. Для Personal Team он действует
7 дней с выдачи. После его истечения установленное приложение не запускается:
нужно снова установить подписанную сборку через Xcode. Проверяй срок заранее,
например раз в 5–6 дней; одно открытие Xcode или приложения срок не продлевает.
Нажатие Run до истечения не гарантирует новый семидневный срок: Xcode может
использовать ещё действующий профиль. Ориентируйся на срок профиля новой сборки.

Повторное доверие — отдельное действие, не обязательный еженедельный ритуал.
Оно может потребоваться при смене сертификата/разработчика или сбросе доверия.
Выполняй его, когда iOS или Xcode сообщает, что разработчик не доверен.
Обычная перезагрузка телефона сама по себе не требует переподписи.

## Если приложение больше не открывается

1. Подключи разблокированный iPhone к Mac. Обеспечь интернет на обоих устройствах.
2. На Mac открой проект командой:

```bash
open -a Xcode "/Users/oleksandr/AlivePicture/_Claude/Network_Graph/personal-network-graph/apps/mobile/ios/App/App.xcodeproj"
```

3. В Xcode выбери схему **App** и свой **физический iPhone**, не Simulator.
4. Синий значок проекта App → TARGETS App → Signing & Capabilities:
   прежняя Personal Team, Automatically manage signing включено,
   Bundle Identifier — `dev.serdiuk.pnet.prototype`.
5. Нажми **▶** и дождись установки и запуска поверх существующего приложения.
6. При ошибке **Developer App Certificate is not trusted** на iPhone:
   Настройки → Основные → VPN и управление устройством → Приложение разработчика
   → твоя учётная запись → Доверять. Если предложено «Разрешить и перезагрузить»,
   выполни это и разблокируй телефон. Затем снова открой PNET или нажми ▶ в Xcode.
7. После успешного запуска нажми **■** в Xcode, отключи кабель и проверь запуск
   с иконки и вход через Face ID.

## Если не помогло

- Если указано «Доверено», но запуск запрещён, сохрани точный текст ошибки Xcode.
  Не отзывай сертификаты и не удаляй профили наугад.
- Если нет раздела разработчика, сначала проверь успешность установки через Xcode.
- Developer Mode оставь включённым. Доверяй только собственной учётной записи.
- Не удаляй приложение, не меняй Team/Bundle Identifier, не очищай Keychain.
- Для одной переподписи неизменённой сборки не нужны npm install, повторный патч,
  миграции или deployment VDS. Если изменился код, используй отдельную инструкцию
  сборки и ios:sync для конкретного изменения.

Контакты и фото хранятся на VDS: истечение подписи их не удаляет. WEB остаётся
доступным при работающем сервере. Вход через Face ID и срок доверия устройства
на сервере независимы от срока подписи Apple; при отзыве/истечении серверного
доверия может понадобиться полная авторизация, а не переподпись.

## Подтверждённый случай

18 октября Xcode показал профиль от 18 октября с «Expires in 6 days».
Это не доказало, что тот же профиль уже находился в установленной сборке.
На iPhone возникло «PNET Prototype Is No Longer Available», затем Xcode явно
сообщил об отсутствии доверия сертификату. После инструкции по восстановлению
доверия владелец подтвердил запуск. Истечение старого профиля отдельно не доказано.
