# v0.43.0 — Production Reliability

Реализация принята 2026-10-03.
Публикация релиза ещё не подтверждена; она завершается обновлением main
и публикацией аннотированного тега v0.43.0 на согласованном коммите.

## Изменения

- Согласованный приватный backup PostgreSQL и contact media.
- Восстановление API после backup и общий lock для backup/deployment.
- Healthchecks API/WEB и deployment с сохранением локальных образов.
- Явная ротация логов: json-file, 10m, пять файлов на контейнер.
- Локальный монитор backup и состояния контейнеров каждые пять минут.
- Retention preview без удаления backup.
- Эксплуатационные инструкции и план улучшения навигации.

## Подтверждённые результаты

- Backup: девять исходных и три целевых теста исправления ownership.
- Deployment: восемь изолированных тестов.
- Monitor: одиннадцать изолированных тестов.
- Retention preview: восемь изолированных тестов.
- Production deployment: API/WEB healthy, БД не изменена.
- Политика логов совпала с работающими контейнерами без их пересоздания.
- Первый backup по расписанию успешно завершён 2026-10-03 в 01:15:42 UTC.
- Монитор после него сообщил status=ok, alerts=[].
- Retention preview: keep=2, candidates=0; ничего не удалено.

## Границы приёмки

Приложение не пересобиралось, повторное восстановление не проводилось.
Production rollback и перезагрузка VDS принудительно не проверялись.
