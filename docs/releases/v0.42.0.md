## Changes

- Temporary contact dragging, with connected edges following their endpoints and
  nearby nodes yielding. No contact, relationship or circle membership is saved.
- Stable radial rest layout with disk separation, and exact eased return on the
  idle deadline (3 seconds), Escape or Restore layout. Holding/hovering blocks
  automatic return; touch uses the same deadline.
- Я behind contacts; INNER, MIDDLE, OUTER draw order remains stable on selection.
- Measured, collision-aware labels; search/details retain full contact names.
- Reduced-motion handling, pointer cancellation and listener/animation cleanup.
- Cancel pending graph requests on unmount to avoid stale renderer creation.

## Scope

WEB only. No API, Prisma, database, authentication or infrastructure changes.
No new dependencies. Node 24 remains the build environment. Icons/photos remain
a separate milestone with authenticated media storage and backup requirements.
Within-circle depth uses stable IDs because creation order is absent from the API.
Dense graphs can hide labels and need zoom/pan; zero overlap at arbitrary density
is not promised. Layout can change after resize or a data refresh.
