# v0.41.0 — Owner Authentication Baseline

Release date: 2026-09-29.
Status: production validated; stable release.
Baseline: v0.40.0 / cd2bc1404cc3e7e607ea3a5cdefb301e8b32f7fe.

## Delivered
- One owner per installation; server-only bootstrap/reset/revoke CLI.
- No guest access, public registration or public owner setup.
- Password + TOTP; encrypted factor and hashed one-use recovery codes.
- PostgreSQL sessions, secure cookies and global API authentication guard.
- CSRF/Origin validation, persistent login limiting and safe auth errors.
- WEB login/logout and private-view teardown on session loss.
- Additive auth migration, deployment overlay and operator documentation.
- Existing outer Basic Auth retained.

## Validation
- Docker Node 24 API and WEB builds passed.
- 17 API/crypto/PostgreSQL tests and 3 WEB client tests passed.
- All 45 protected controller routes rejected unauthenticated requests.
- Existing locked dependency versions preserved; Prisma remains 6.19.3.
- Production backup successfully restored in an isolated database.
- Production auth migration and owner CLI bootstrap completed.
- API health and WEB returned HTTP 200.
- Private API routes returned HTTP 401 without a session, directly and via WEB.
- External unauthenticated request returned HTTP 401.
- Database container was not recreated or restarted.
- User confirmed browser acceptance after deployment.
- API, WEB and DB had restartCount=0 at the production checkpoint.

## Operations
Always include compose.auth.yaml and the private operator environment file
when recreating application services. See ../security/owner-auth-operations.md.
Never commit installation keys, credentials, provisioning files or recovery codes.
